## Visão Geral do Projeto
Sistema web completo de comanda digital para hamburgueria, desenvolvido com:
- **Frontend:** HTML5 + CSS3 + JavaScript puro
- **Backend:** ASP.NET 8 Web API com Clean Architecture
- **Banco de dados:** MySQL (gerenciado via phpMyAdmin)
- **Padrões de projeto implementados:** Repository, Factory, Command (CQRS leve)
- **Camadas:** Presentation → Application → Domain → Infrastructure

## Funcionalidades
- Cardápio interativo com imagens
- Carrinho de compras com atualização em tempo real
- Finalização de pedido com número da mesa e observações
- Persistência completa no MySQL
- Documentação automática com Swagger
